# LEGEND BALL X1000

An original, mobile-first cosmic martial-fantasy game in development by Soft Tech.

This is an isolated virtual-credit research prototype derived from an immutable
Skygate v0.14.3 source snapshot. It is not a new RNG engine, certified gaming
product, real-money platform or approved production release.

- Layout: 6 reels x 5 rows, mobile portrait
- Unmodified source: tumble, pay-anywhere, 15 Free Spins on 4+ Scatter,
  5 retrigger Free Spins on 3+ Scatter during bonus, original multiplier
  table, 5000x round cap, Buy Spin and Bonus Booster.
- New original art direction: Aster Varn, Veylorn crystalline leviathan,
  six rune-ball Scatter artwork ideas (not implemented), distinct
  symbols, UI, audio and animation still to be created.
- Scatter is still generated per cell. There is no guaranteed
  maximum of one Scatter per column.

Local: npm test then npm start. Game at /play/, editor at /studio/.
The current cloned game still displays source Skygate artwork.
It must be fully replaced with original art before design approval.
